Platform update

GoreeCloud’s public platform map catches up with the software

The current connected GoreeCloud source inventory spans 57 repositories: 40 public and 17 private. The public websites reflect the broader native-software direction, including GoreeCloud AI, Code, Documents, Messenger, Gateway, Quill, Mesh, File Manager, Maps, App Store, and GoreeCloud Index while keeping lifecycle and production claims evidence-scoped. Glaze UI 2.1.0 is the current Stable design-system baseline. The six substantive platform systems are Glaze UI, Privacy Shield, Wardveil Security, Everkeep, GoreeCloud Mesh, and GoreeCloud Identity.

Portfolio and website update · August 31, 2026

Developer platform

GoreeCloud Code replaces the idea of a forge as the product boundary

An earlier August 25 direction described self-hosted Gitea as the planned permanent source-control authority. That direction has been superseded. GoreeCloud Code is now the first-party developer and source-control platform for repositories, collaboration, CI/CD, packages, security, and AI-assisted development. Forgejo is the initial replaceable infrastructure foundation: important infrastructure, but not the permanent GoreeCloud product boundary. GitHub can remain useful for migration, public collaboration, mirrors, or interoperability without defining the long-term application architecture.

Suite development update · August 29, 2026

Design

Glaze UI 2.1 is the current Stable production target

Glaze UI 2.1.0 is the current Stable GoreeCloud design-system baseline. Its material hierarchy runs from Canvas through Surface, Soft Glaze, Glaze, Deep Glaze, and Live Glaze, with a clearer rule: content stays solid while interaction is glazed. The Stable contract adds explicit clarity and density modes, a 56px Touch Assistance floor, large-text fallbacks, deterministic material budgets, and stronger reduced-transparency, reduced-motion, increased-contrast, forced-colors, and constrained-rendering behavior. Glaze UI 2.0.0 is the immediately preceding historical Stable baseline and current consumers must migrate and earn repository-local 2.1 acceptance.

Identity joins the public platform model

GoreeCloud Identity is a substantive platform system responsible for identity, authentication, authorization, accounts, devices, credentials, sessions, and delegated authority. GoreeCloud Mesh coordinates relationships and evidence without taking over Identity authority, just as it does not replace Privacy Shield, Wardveil Security, Everkeep, or Glaze UI.

Platform architecture update · August 29, 2026

Platform direction

Native applications become the required GoreeCloud end state

GoreeCloud requires every GoreeCloud application to become original native-from-the-ground-up software at the product and application layer. Maintained forks and adopted complete application codebases are transitional migration, compatibility, testing, historical, or reference sources only. Mature libraries, standards engines, codecs, rendering engines, cryptographic primitives, operating-system/runtime components, and comparable foundations may remain when replacing them would materially increase technical risk. Current Stable qualification remains evidence-scoped and includes applicable Glaze UI, Wardveil Security, Privacy Shield, Everkeep, and Identity requirements.

Bookmarks

Bookmarks moves into original GoreeCloud code

Development update · August 29, 2026

Design

Semantic color remains a system contract

Glaze UI defines system-wide semantic color roles for accent, surface, selection, focus, success, information, warning, danger, protected, restricted, online, offline, syncing, and unavailable states. Color remains a presentation layer rather than an authority: important meaning must also survive through labels, icons, shapes, patterns, or equivalent non-color cues, and Wardveil Security, Privacy Shield, Everkeep, Mesh, Identity, and application logic remain authoritative for their underlying state.

Design-system direction · current contract carried forward in Glaze UI 2.1

Glaze UI, Wardveil Security, Privacy Shield, Everkeep, GoreeCloud Mesh, and GoreeCloud Identity are integral platform systems with distinct authority. Drive reaches its first persistent storage milestone

GoreeCloud Drive persists file and folder metadata in PostgreSQL and connects node CRUD to trusted-principal and Space-membership authorization. The milestone keeps fail-closed service enforcement, Drop-only privacy preservation, strict request validation, and the larger authorization-first direction intact.

Drive update · August 24, 2026

Suite

Focused apps instead of one giant cloud

GoreeCloud deliberately separates files, synchronization, documents, photos, video, music, mail, messaging, AI, location, maps, tasks, calendars, contacts, notes, monitoring, networking, identity, developer tooling, application distribution, and other responsibilities into focused products that can interoperate without becoming inseparable.

Development

Open-source foundations, native GoreeCloud products

GoreeCloud continues to use mature open-source libraries, standards, protocols, codecs, engines, runtimes, databases, and infrastructure where they are the safer technical choice. At the product layer, however, GoreeCloud applications are required to become original GoreeCloud implementations rather than permanent third-party application forks.

Resilience

Everkeep connects backup to long-term preservation

Backup is only one part of continuity. Everkeep represents the broader expectation that important information remains recoverable, portable, understandable, and transferable even as applications and infrastructure change. Its Continuity Center surfaces that model without upgrading unsupported recovery claims.

History

Preserving the story behind the platform

Changelogs, the public Archive, the Blog, and the Autobiography project are complementary ways to preserve technical history, decisions, lessons, superseded directions, and the long-term evolution of GoreeCloud.
