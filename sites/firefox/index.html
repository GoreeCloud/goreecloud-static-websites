Public contract

Extensions should explain what they do—and what they do not prove.

First-party sourceCurrent extension code is governed from the consolidated GoreeCloud Firefox repository.
Scoped permissionsBrowser permissions should remain tied to the extension’s purpose rather than convenience.
Release truthSource version, source state, signing, distribution, and accepted Stable status remain separate evidence.
Privacy boundariesExtension-local privacy behavior does not manufacture platform-wide Privacy Shield authority.
Inspectable developmentSource, documentation, security notes, and change history remain reviewable in the canonical repository.
Portable browser toolingThe extensions complement Firefox without turning the browser into an opaque GoreeCloud dependency.
