Release discipline

Source, signing, and Stable status stay separate.

First-party source

New Firefox-specific development belongs in the canonical GoreeCloud extensions repository after migration acceptance.

Manifest V3

Repository validation checks extension identity, permissions, version agreement, required documentation, and packaging integrity.

Mozilla signing

Unsigned packaging success does not establish Mozilla signing, release acceptance, or Stable status.

Privacy boundaries

Broad host permissions and privacy-sensitive behaviors require explicit review rather than silent expansion.
