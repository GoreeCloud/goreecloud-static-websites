# Homepage platform-foundations integration

The GoreeCloud public homepage must present the three shared GoreeCloud platform foundations together and preserve their separate scopes:

- **Glaze UI** — design and interaction authority; canonical public destination: `https://design.goreecloud.com/`.
- **GoreeCloud Privacy Shield** — privacy and privacy-control identity; canonical public destination: `https://privacy.goreecloud.com/`.
- **Wardveil Security by GoreeCloud** — security and protection identity; canonical public destination: `https://security.goreecloud.com/`.

The homepage presentation is a discovery and identity surface. It must not imply that Privacy Shield and Wardveil are the same authority, that either identity wraps the other, that the static website implements an unverified Privacy Shield enforcement runtime, or that the website carries a blanket Wardveil protection assurance.

The dedicated Privacy and Security pages remain authoritative for the public website's detailed privacy and security boundaries. Glaze UI remains the website design-system authority.
