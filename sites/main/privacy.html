Public website privacy

Privacy at GoreeCloud

This public website uses no advertising and keeps optional analytics off unless you explicitly allow it. Session replay, broad behavioral autocapture, remote fonts, and user profiling are not part of the approved website telemetry contract.

Website behavior

Privacy-preserving by default.

Optional analytics starts offPostHog is not contacted until you choose “Allow anonymous analytics.” Choosing “No thanks” leaves analytics disabled.
One minimized eventIf allowed, GoreeCloud sends only a website opened event under the initial telemetry contract.
Local preferencesAppearance and analytics choices may be stored locally in your browser so those choices can persist.
No account requiredThis informational website does not require a GoreeCloud account to read public content.

Optional analytics

A small, explicit PostHog boundary.

If you allow anonymous analytics, this website loads the PostHog JavaScript library from PostHog US Cloud and sends one minimized website opened event to PostHog US Cloud. GoreeCloud uses that event only to understand whether the public website is being used.

CollectedThe event includes the application name, environment, telemetry schema version, a non-persistent in-memory event identifier used by the SDK, and limited SDK routing/version fields.
Not collected by this contractNo page contents, form contents, search text, contact details, message text, filenames, clipboard content, URL query parameters, referrer details, session replay, heatmaps, click autocapture, automatic page views, or performance telemetry.
Network metadata minimizedThe PostHog project is configured to discard client IP data. The event also disables GeoIP enrichment, so GoreeCloud does not use the connection IP to add location properties to this analytics event.
No person profileThe event explicitly disables person-profile processing and the website does not call PostHog identification APIs.
Consent required

You stay in control.

Your analytics choice is stored under the first-party browser key goreecloud-analytics-consent. You can change it through the site’s Analytics preferences control. Revoking consent stops future capture from this website. The PostHog project currently has a 12-month event-retention setting; GoreeCloud will review that retention as the integration evolves.

Hosting and browser storage

Keep the rest of the surface small.

Cloudflare PagesThe public website is hosted through Cloudflare Pages under its separately governed deployment lifecycle.
Appearance preferenceThe site may use localStorage for the goreecloud-theme preference. System mode does not require a stored theme preference.
No referrer disclosureThe site sends a Referrer-Policy: no-referrer response header to reduce browser referrer disclosure.
External links are explicitFollowing a link to another website leaves this public-site privacy boundary and becomes subject to that destination’s practices.

Privacy Shield boundary

A privacy website is not privacy authorization.

Privacy Shield is GoreeCloud’s dedicated privacy authority. This page can explain public privacy practices, but it does not create Privacy Shield authorization, prove application-level privacy acceptance, or convert missing evidence into a stronger state. Visit privacy.goreecloud.com for the dedicated Privacy Center.
