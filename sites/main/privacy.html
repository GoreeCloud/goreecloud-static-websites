Privacy at GoreeCloud

GoreeCloud is built around privacy by default. Privacy Shield is GoreeCloud's platform-wide privacy and privacy-control identity. This statement describes the public website and its browser-side code.

Last updated: August 31, 2026

Privacy Shield

No behavioral tracking.

This public website does not intentionally use analytics, advertising, behavioral tracking, third-party telemetry, fingerprinting, or third-party browser resources such as scripts, stylesheets, fonts, and rendered images. Browser-loaded site resources are kept on the GoreeCloud origin; external sites are reached only when you choose to follow a link.

Three complementary foundations on this page

Glaze UI governs design and interaction. Privacy Shield governs privacy identity and privacy responsibilities. Wardveil Security governs security and protection identity. These authorities remain separate within GoreeCloud's broader six-system platform model.

Privacy Shield boundary on this website

The website's no-analytics, no-advertising, local-resource, data-minimization, and local-only appearance-preference behavior aligns with Privacy Shield. This page does not claim a separate Privacy Shield runtime adapter or Browser-style request-blocking engine. Actual privacy state is established by reviewed source, browser behavior, headers, deployment configuration, and validation.

Information collected by the website

The public site does not provide an account sign-in, web form, advertising profile, or marketing pixel. GoreeCloud's browser code does not create a behavioral profile or send browsing activity to an analytics service.

Appearance preferences

If you choose Light or Dark mode, the site stores that choice under goreecloud-theme using localStorage. Returning to System mode removes the override. System mode requires no stored preference. The preference is used only by local GoreeCloud code and is not sent to analytics or advertising services.

Hosting and network delivery

The website is deployed through Cloudflare Pages. Network delivery necessarily uses hosting infrastructure, but this repository does not add analytics or advertising code to build visitor profiles. External links operate under their destination policies.

Referrer privacy

GoreeCloud configures Referrer-Policy: no-referrer, preventing the browser from intentionally sending the GoreeCloud page URL in the HTTP Referer header when following a link.

External links and email

When you leave GoreeCloud, the destination site's privacy practices apply. Email links use mailto:; messages are handled by your email client and involved email services, not a GoreeCloud web form.

Security reports

See the GoreeCloud security-reporting policy and /.well-known/security.txt before testing or reporting an issue.

Questions and changes

If website privacy behavior changes materially, this statement should be updated. Questions can be sent to goreecloud@gmail.com.
