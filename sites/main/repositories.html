GoreeCloud source

Repositories are evidence, not a scoreboard.

GoreeCloud creates and evolves repositories continuously. To avoid publishing a count that becomes wrong as soon as new work begins, the live GoreeCloud GitHub organization is authoritative for current inventory. This page is a reviewed public-safe guide to major source roles.

Directory principle

Repository presence is not release status.

A repository, commit, milestone, or public listing does not by itself establish deployment, production acceptance, Stable qualification, protection, privacy, or recovery state. Use each project’s authoritative records and exact evidence for those claims.
