Wardveil Security by GoreeCloud

Responsible security reporting

If you believe you found a security issue affecting a public GoreeCloud property or GoreeCloud software, report it privately to security@goreecloud.com.

Email security@goreecloud.comRead security.txt

Reporting

Give enough detail to reproduce the issue safely.

Include the affected public property or repository, a concise description, reproduction steps when safe, observed impact, and any relevant version or revision. Do not send reusable credentials, private keys, or unrelated personal data.

Report privately firstUse the published security contact before public disclosure when the issue may put users or systems at risk.
Minimize sensitive dataShare only what is needed to understand and validate the report.
Keep scope explicitA finding in one application or website does not establish compromise or protection state elsewhere.
Evidence over reassuranceSecurity status remains tied to current evidence and the authority responsible for the affected system.

Platform authority

Seven complementary Integral Platform Systems.

Glaze UI governs design and interaction; Privacy Shield governs privacy authorization; Wardveil Security governs security evidence and protective state; Everkeep governs continuity evidence; GoreeCloud Mesh coordinates relationships and evidence; GoreeCloud Identity governs identity and delegated authority; and GoreeCloud Manager provides bounded administrative and operational visibility. None inherits another system’s authority merely because their public surfaces are linked.

Security Center

Public security information has its own dedicated surface.

Visit security.goreecloud.com for Wardveil Security information. This reporting page does not itself establish a protected state.
