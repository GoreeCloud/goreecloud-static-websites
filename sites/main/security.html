Responsible security reporting

I welcome good-faith reports about public GoreeCloud properties and software. Wardveil Security is GoreeCloud's platform-wide first-party security system and shared security plane. What to include

  • Affected public URL, repository, application, or version.
  • Vulnerability description, impact, and minimal reproducible steps.
  • Relevant evidence with unrelated sensitive data removed.
  • Any identified mitigation.

Testing boundaries

This policy does not authorize testing of private family infrastructure, private services, accounts, devices, internal networks, administrative interfaces, credentials, or non-public data.

  • Do not access, retain, modify, or disclose data that is not yours.
  • Do not perform destructive testing, denial-of-service, social engineering, credential attacks, or disruption.
  • Do not use high-volume automation that could degrade a service.
  • Allow a reasonable remediation opportunity before public exploit disclosure.

Wardveil identity boundary

Sentinel Fold is the owner-approved standalone primary visual mark. Wardveil Security and Security Center text are supporting identity, not part of the emblem. Branding is not security evidence. Any Wardveil protection status requires defined scope, current authoritative evidence, and applicable accepted runtime integration; policy intent, transport, storage health, scanner branding, or a Security Center view cannot prove execution.

Malware-protection boundary

ClamAV is the initial replaceable signature engine beneath Wardveil Scan. The production ClamAV scanner runtime is deployed and accepted at the scanner-evidence layer. That acceptance does not establish end-to-end Wardveil Scan application acceptance or a blanket antivirus claim: authenticated application-consumer routing, quarantine execution, and environment-specific integration evidence remain separately gated before broader protection claims are made.

How reports are handled

Credible reports are prioritized by impact, exploitability, exposure, and safety. GoreeCloud does not currently offer a bug bounty or guaranteed response timeline. This guidance does not create authorization to access systems, accounts, or data.
