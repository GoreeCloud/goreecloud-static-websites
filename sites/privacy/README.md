This package contains only the Privacy Center public static source, deterministic build contract, and approved public Privacy Shield icon. Generated `website/dist`, Privacy Shield runtime code, adapters, internal contracts, configuration, and service implementation remain outside static-site authority.

The central package intentionally preserves the active Glaze UI 2.1.0 website source. Historical adoption records remain available in the legacy repository history and are not required to reproduce the public artifact.

Production source cutover, Cloudflare Pages configuration, DNS/HTTPS verification, and legacy-source retirement remain separate acceptance gates.
