# GoreeCloud Wardveil Security Static Website

Canonical source repository: `GoreeCloud/goreecloud-static-websites`

- Site root: `sites/security`
- Canonical domain: `security.goreecloud.com`
- Legacy source repository: `GoreeCloud/goreecloud-wardveil-security`
- Reviewed source commit: `ad8a2163d2e22cab232f80e320a9c72a70946545`

This package contains only the Security Center public static source, deterministic build contract, active GLAZE UI V1.1 / 1.1.0 web subset, and approved Sentinel Fold public icon. Generated `website/dist`, Wardveil runtime services, Scan/Quarantine implementation, authorization/evidence contracts, deployment internals, and unrelated security authority remain outside static-site authority.

Historical design/adoption files remain preserved in the legacy repository history and are not required to reproduce the active published artifact.

Cloudflare Pages source cutover, DNS/HTTPS validation, production acceptance, and legacy-source retirement remain separate gates. This static-site migration does not establish Wardveil runtime production acceptance or authorize a broader “Protected by Wardveil” claim.
